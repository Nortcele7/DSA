## 🚀 Getting Started

### Prerequisites
- C++ compiler (GCC, Clang, or MSVC)
- C++11 or higher

### Compiling and Running

To compile any C++ file:
```bash
g++ filename.cpp -o filename
./filename
```

For Windows:
```powershell
g++ filename.cpp -o filename.exe
filename.exe
```
